# OpenManager Game Vision

## Spielerfantasie
Ich führe eine Mannschaft, entwickle Menschen und baue einen Verein auf.

## Kernbereiche
1. Mannschaft und Beziehungen
2. Aktiver Spieltag
3. Sichtbarer Vereinsaufbau

## Designregeln
- Entscheidungen vor Tabellenarbeit
- Informationen verständlich darstellen
- Jede Entscheidung soll sichtbare Folgen haben
- Spieler sind Persönlichkeiten, keine reinen Werte
- Das Matchcenter ist das Herz jeder Spielwoche
- Langfristige Vereinsentwicklung muss sichtbar sein

## Nicht-Ziele
- Keine vollständige Football-Manager-Kopie
- Keine hunderten unverständlichen Datenfelder
- Keine verschachtelte Menüstruktur
- Keine Funktionen nur um der Simulationstiefe willen
